# DigiKey Tutorials
Code from the electronics and AI/ML tutorials I post on TikTok. Each folder in this repo pairs with a video, so you can follow along, break things, and build on top of it.

## What's inside

- **Train_Model_Vision** — Train and run a YOLO computer vision model (image, video, and webcam inference) using Ultralytics + PyTorch.

More folders will be added as new tutorials go up.

## Getting started

Each project has its own `requirements.txt`. From inside the project folder:

```bash
pip install -r requirements.txt
```

Then check the folder's code/notebook for usage instructions.
